# Daily Workflow

1. Start JCC and review Follow-ups / Interviews.
2. Confirm the active Master CV, Target Roles and Target Locations in Settings when needed.
3. Choose **RUN SEARCH NOW**. A fresh install already has auto-managed SYSTEM sources; manually adding a source is optional advanced configuration. In AUTO mode, discovery can also prepare eligible Strong/Good packages while JCC is running.
4. Review jobs by Recruiter Match first, then ATS Exact, posting-date confidence, source/application URL and evidence gaps.
5. Open a job workspace for the full JD, requirement evidence, ATS wording, tailoring plan and package actions.
6. Tailor from the immutable Master. JCC uses evidence-safe Google XYZ, optionally accepts only verified line-level rewrites from a loopback local writer, runs Humanizer, verifies facts/metrics, reruns Recruiter/ATS, and creates child DOCX/PDF/Markdown files without overwriting the Master.
7. Review template-preservation status/warnings, post-tailor integrity, cover letter, application answers, contact research and unsent outreach. Unknown work authorisation, salary, relocation and start-date facts remain `USER CONFIRMATION REQUIRED`.
8. Open the official application URL and submit manually. JCC does not click the external final Submit/Send button.
9. Use **MARK APPLIED** only after submission and select the exact physical CV used. JCC snapshots and SHA-256 hashes that file and stores the JD snapshot.
10. Follow-up drafts are allowed only from recorded workflow events. Interview preparation uses the exact submitted CV and JD context. **OPEN CV USED** reopens the immutable submitted artifact.

The Knowledge Graph can remain open; SSE updates it without reload. Humanizer/writing-agent relationships are represented through the existing skill/agent Markdown wikilinks. Obsidian is an optional view of the same Markdown knowledge.
